# lucas-site

Public homepage and privacy policy for **Lucas**, the Google OAuth consent app (project
`gen-lang-client-0281349477`) behind Lucas's Google Calendar connection. Google requires both pages
before the app can move from Testing to In production, which ends the seven-day token expiry.

- Served by GitHub Pages at https://lucas.familees.net/ (`CNAME`); DNS: `lucas` CNAME `arain11.github.io`.
- Facts behind the privacy page (checked 9 Nov 2026): model provider OpenAI via the ChatGPT
  subscription (`~/.hermes/config.yaml`), replies over Telegram, private tailnet dashboard reads
  upcoming events, Hermes session history kept with auto-prune off, gog credentials in an encrypted
  file keyring. If any of these change, update `privacy.html` and its effective date.
- Background: `~/.hermes/notes/google-calendar-oauth-handoff-2026-11-09.md`.
